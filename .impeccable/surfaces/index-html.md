# Surface brief: landing page (index.html)

Scope and mode: Persuade. Whole-page redesign of the Showdown Helper landing page (replaces the sage/charcoal taste-skill build).
Audience, job, action: introductory VGC players; learn what the extension does, install it unpacked in three steps; main action "Get the code on GitHub" → https://github.com/lkz404/showdown-helper.
Proof and content: real panel captures from the extension's own code (real Pikalytics usage, real @smogon/calc numbers), no invented claims. Pinned by the user: white, sand and cobalt; cleaner animations; no AI-slop tells.
Unresolved: canonical domain, Chrome Web Store link (neither exists).

## Direction contract

THESIS: The page is the team list sheet a VGC player hands the judge: a printed white form on a sand desk, with everything the tool knows filled in cobalt ink. It refuses the category default of a dark UI window floating over a card grid with a gradient.
OWN-WORLD: Sand desk, white sheet, 1px navy rules, sand shaded field bands, tiny condensed-caps field labels, one grotesque (Archivo) in two widths. Printed text is near-black navy, filled entries are cobalt. Pen marks (ticks, rings) are drawn SVG strokes, never a handwriting font. No gradients, glows, glass, soft shadows or rounded cards. Radius 0 to 2px.
STORY: A new player sees the opponent's top five moves and the damage to their own Pokémon, understands KO turns the number red, follows three install steps, and takes the GitHub action.
